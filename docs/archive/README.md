# 历史文档归档

本目录保存仍有追溯价值、但不再指导当前开发或现场操作的历史设计和验证记录。使用当前系统时，请回到 [文档导航](../README.md) 选择现行规范。

归档前必须在对应 Issue/PR 记录原因，并在文件顶部标注替代文档或已知失效范围。原始秘密、设备备份、未整理日志、临时截图和本机环境文件不进入本目录；这类材料按[文档放置规则](../engineering/document-placement.md)留在受控位置或删除。
