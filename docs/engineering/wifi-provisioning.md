# 设备 Wi-Fi 热点配网

设备不再要求用户运行串口脚本才能首次连接 Wi-Fi。首次启动没有保存的 Wi-Fi 凭据、保存的网络连续连接失败，或用户主动请求时，设备会进入一个最多 5 分钟的本地 SoftAP 配网流程。

1. 在手机 Wi-Fi 列表选择 `VoiceLife-XXXXXX`；设备屏幕会完整显示本次随机生成的 8 位热点密码。
2. 用手机连接该热点；系统的网络登录页会自动打开。没有自动打开时，访问 `http://192.168.4.1`。
3. 选择扫描到的家庭 Wi-Fi 或手动输入 SSID，填写密码并提交。
4. 设备先以候选凭据连接。只有拿到 STA IP 后，才会把新凭据写入 HMAC 加密的 `linx_secrets/wifi` 命名空间；失败时原有 Wi-Fi 凭据不变。

主动重新配网使用同一块物理按键：长按 2 秒会把一次性的重新配网请求写入加密的 `linx_secrets/wifi` 命名空间并重启到热点页面。设备开始该流程时立即消费标记，因此取消、超时或候选网络失败后下次启动仍会尝试原有 Wi-Fi。该标记不含身份或 Wi-Fi 密码；短按仍维持原有的聊天语义。热点和本地 DNS/HTTP 服务在验证成功或超时时关闭，设备回到 STA 模式。

串口配网协议仍只作为无显示诊断环境的回退，不是面向用户的正常路径。配网页面、日志和 URL 不回显家庭 Wi-Fi 密码；热点密码仅通过本机屏幕提供。
