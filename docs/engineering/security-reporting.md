# 安全报告规则

本规则说明当前版本的安全支持范围和私密报告入口。安全漏洞不得通过公开 Issue、PR 或讨论区提交；普通错误和应用日志仍应保留可定位所需的明文，只有秘密和隐私字段需要排除。

## 支持范围

安全修复优先覆盖 `main` 和最新正式 Release。`0.x` 阶段接口仍可能变化，修复说明必须写明受影响版本、临时缓解和升级方式。

## 私密报告漏洞

使用 GitHub 的 [Private Vulnerability Reporting](https://github.com/1024XEngineer/VoiceLife/security/advisories/new) 提交以下内容：

- 受影响版本或 commit；
- 攻击前提和影响；
- 最小复现或概念验证；
- 已知缓解办法；
- 是否可能已经泄露真实数据。

团队确认后在同一私密线程协调修复、验证和披露时间。安全修复合并前不要求公开完整利用细节。

## 特别关注

VoiceLife 处理设备凭据、语音和私人日程。明文传输 bearer token、越权读取或修改日程、日志泄露、未验证 OTA、远程代码执行、持久化损坏导致跨用户数据暴露，以及 IM 动作身份或幂等绕过都按安全问题报告。
