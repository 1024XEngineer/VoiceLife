4 STEPS

接入教程

  1. 1

    获取并保存 API Key

    在灵矽控制台获取 API Key，填写到右侧。它只保存在本机，不会在页面中回显。

  2. 2

    开通 MCP 接入点

    复制临时 X-MCP-Token，在 MCP 广场添加 Streamable HTTP 接入点。

    MCP URL https://xrobo.qiniu.com/v1/mcpproxy/mcp 认证模式 Normal Header X-MCP-Token

  3. 3

    绑定到日程 Agent

    在控制台把接入点绑定到目标 Agent，保存角色提示词；如有 Agent ID，可填写到右侧。

    打开灵矽文档 ↗

    绑定 Mac 语音设备
