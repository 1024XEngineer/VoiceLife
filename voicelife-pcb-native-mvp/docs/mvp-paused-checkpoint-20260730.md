## 用户现场操作清单

开始前不要按 BOOT、不要重新配网、不要重刷固件。先回复“开始真机测试”，等待串口抓取和分区快照完成，并收到“可以说了”。

收到信号后依次说：

1. “你好小智，两分钟后提醒我喝水。”
2. 听到创建成功后说：“查询我今天接下来的日程。”
3. 等待两分钟，确认 PCB 是否主动播报喝水提醒。
4. 播报后说：“知道了，关闭提醒。”

最后只需反馈三件事：是否听到创建确认、是否听到自动播报、声音是否清楚且无爆音。其余参数和日志由自动化侧记录。
